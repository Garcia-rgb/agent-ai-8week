# 8 周课程执行表

课程资源已于 2026-09-03 按官方页面重新核对。先阅读 [2026 Agent 课程与框架核对报告](resources_2026.md)，明天直接执行 [Day 1](tomorrow_start.md)。

每周 20–25 小时，建议工作日每天 2 小时、周末每天 5–7 小时。

固定节奏：

- 每天 45–60 分钟关闭 AI 独立编码。
- 学习前先写“今天要回答的三个问题”，学习后闭卷回答。
- AI 生成代码必须逐行解释；无法解释的代码不能提交。
- 每周日完成一次无 AI 重写和一次项目口述录音。
- 从第 6 周开始每周进行 15–20 次针对性投递。

| 周 | 主题 | 仓库交付物 | 通过标准 |
|---|---|---|---|
| 1 | Python 与 HTTP | CLI 任务管理器、FastAPI CRUD | 无 AI 完成基础增删改查 |
| 2 | 数据库与测试 | 会话/消息服务、pytest、Docker | 能解释事务、索引和依赖注入 |
| 3 | LLM 与工具 | 手写 Agent Loop、模型适配 | 能解释工具参数为何不可信 |
| 4 | RAG | 文档导入、混合检索、引用 | 能区分检索错和生成错 |
| 5 | LangGraph | 状态路由、人工确认 | 失败后状态可理解、写操作受控 |
| 6 | 生产化 | 审计、评测、CI、部署 | 能展示失败样本和安全测试 |
| 7 | 作品打磨 | README、架构图、演示视频 | 陌生人 10 分钟内可运行 |
| 8 | 面试投递 | 简历、题库、投递追踪 | 完成模拟面试和 15–20 次投递 |

资源主线不是“课程越多越好”：Agent 模式使用 DeepLearning.AI 与 Hugging Face Agents Course，工程主线使用本仓库，编排主线使用 LangGraph 官方文档，MCP 使用 Hugging Face MCP Course 与最新官方规范。
