# 第 1 周：Python 工程基础

## 日程

- Day 1：环境、变量、容器类型；闭卷实现列表去重和词频统计。
- Day 2：函数、类型提示、异常；为输入解析写 5 个测试样例。
- Day 3：类、dataclass、文件和 JSON；实现本地任务仓库。
- Day 4：HTTP、REST、状态码；阅读 FastAPI 请求/响应模型。
- Day 5：完成 CLI 任务管理器，支持新增、完成、删除、持久化。
- Day 6：把任务管理器改成 FastAPI CRUD，手写至少 4 个接口。
- Day 7：无 AI 重写一个接口，录制 5 分钟代码讲解并复盘。

## 必读

- Python 官方教程第 3–9 章
- FastAPI Tutorial 的 First Steps、Request Body、Dependencies
- Pro Git 的基础、分支、撤销章节

## 验收问题

1. `list`、`dict`、`set` 的选择依据是什么？
2. 为什么不应捕获裸 `Exception` 后什么也不做？
3. 400、401、403、404、409 和 500 分别代表什么？
4. Pydantic 模型与数据库模型为什么要分开？
