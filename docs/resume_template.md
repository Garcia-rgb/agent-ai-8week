## 项目：企业知识库客服 Agent

时间：2026.xx–2026.xx｜个人项目｜GitHub/演示地址

- 面向企业客服知识分散和人工查询效率低的问题，设计并实现支持文档导入、知识问答、订单查询和工单创建的 Agent 服务。
- 使用 FastAPI、PostgreSQL/pgvector 与 LangGraph 构建会话、检索和工具工作流，通过文档去重、混合检索、Rerank 实验与来源引用提高回答可验证性。
- 将工单创建设计为需要人工确认的写操作，使用签名令牌、有效期和防重放审计阻止越权或重复提交。
- 建立 40 条固定评测集并对三组切块参数进行对比；填写真实的最佳通过率、失败类型和改进幅度。
- 使用 pytest 覆盖文件校验、检索、工具安全、用户隔离和确认流程，通过 Docker Compose 与 CI 提供可复现运行环境。
